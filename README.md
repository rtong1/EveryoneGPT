# 知伴

给习惯说话、拍照的人用的中文生活助手。打开首页就能说话、选照片提问或打字。网页和鸿蒙客户端使用同一个界面与家庭服务。

## 问答和新话题

知伴通过 AIHubMix 自动选择问答模型。日常聊天、读照片和解释身体指标使用 GPT-6.1 Terra，按问题调整推理强度。需要权衡多个条件、比对不同说法或深入分析时，使用 GPT-6 Astra。例如，拍套餐单问“每月多少钱”用 Terra，接着问“算上安装费和半年后解约的费用，哪种划算”用 Astra。紧接着问“三个月呢”会继续用 Astra。换话题后按新问题重新判断。服务端根据本轮提问及对话上下文作选择，每轮只向 AIHubMix 发送一次问答请求。[Terra](https://aihubmix.com/model/gpt-6.1-terra) · [Astra](https://aihubmix.com/model/gpt-6-astra)

聊天达到四轮或最近内容较长时，如果用户提出了不同主题，发送前会询问“在新聊天里问”还是“接着聊”。另开后只发送当前问题和附图，旧聊天折叠在本页，可展开回看。接着聊会保留最近的上下文，接下来三轮不重复提示。每次请求最多附上最近五轮完整问答及两张图片，并按估算的输入量裁剪历史。关闭或刷新页面会清除聊天。

录音通过 AIHubMix 调用 Whisper Large V3 转成文字。朗读优先使用设备自带的中文语音，云端朗读通过 AIHubMix 调用 GPT-4o Mini TTS。

## 先在电脑上用

1. 解压整个项目。Mac 上双击 **启动知伴.command**。Windows 或 Linux 在解压目录打开终端，运行 `node server.mjs`，再用浏览器打开 **http://127.0.0.1:8787/**。运行需要 Node.js 22.12 或更新版本，无需安装第三方软件包。
2. 家人打开 **设置 → 问答服务**，填写 AIHubMix API Key，保存后就可以提问。个人密钥只用于这次页面会话。家庭长期使用可按下一节把密钥放在服务端。
3. 点 **开始说话**，允许麦克风，说完点 **说好了**。知伴会回答并朗读；系统要求手动播放时，点播放即可。点 **拍照提问**，在相册确认所选照片后，知伴就会看图回答，文字可以留空。点 **字号** 可切换大字。

在本机使用服务端密钥时，将 `.env.example` 复制成 `.env`，填写 `AIHUBMIX_API_KEY`。Mac 启动器会读取这个文件；其他系统运行 `node --env-file=.env server.mjs`。保留默认的本机监听地址，只有这台电脑能使用这项本机配置。

AIHubMix 按所用密钥向其所属账户计费。升级旧版本时，请在 AIHubMix 创建专用密钥，填入新的 `AIHUBMIX_API_KEY`，再重启家庭服务。已有家庭服务码可以继续使用。[AIHubMix 控制台](https://console.aihubmix.com/) · [模型价格](https://aihubmix.com/models)

## 在手机上使用家庭服务

将网页和服务部署在同一 HTTPS 域名下。手机只需访问家庭网址，家庭服务器需要能通过 HTTPS 连接 `https://aihubmix.com/v1`。

**使用随包的 Docker 部署配置**（由管理服务器的家人操作）

1. 将自己的域名指向家庭服务所在的服务器，准备好域名接入，并开放 TCP 80、443 端口。服务器需有 Docker 和 Compose。
2. 在服务器上解压项目，将 `.env.example` 复制成 `.env`。把 `APP_DOMAIN` 填为实际域名，只写域名。将 AIHubMix 密钥填入 `AIHUBMIX_API_KEY`，在 `FAMILY_ACCESS_CODE` 中设置一个随机家庭口令（12 至 512 个字符）。例如可用 `openssl rand -hex 16` 生成。在 Linux 上运行 `chmod 600 .env`，让该文件仅对所属用户可读写。
3. 在项目目录运行 `docker compose up -d --build`。Caddy 负责 HTTPS，把同一域名下的网页和接口转给应用。也可沿用现有 HTTPS 网关，保留原 Host，在应用环境设置 `PUBLIC_ORIGIN=https://你的实际域名` 和对应的监听地址。
4. 用手机流量打开家庭 HTTPS 网址。首次由家人在设置中输入家庭服务码（部署时设置的家庭口令），并按需记住这台设备；之后长辈直接使用。记住的登录有效期为 30 天。更换服务端家庭口令并重启服务会使已有设备登录失效。
5. 先用一张普通生活照片和一句语音验证看图、语音识别、朗读，再开启个人健康记录。模型服务费用归服务端密钥所属账户。

**鸿蒙手机**：使用 DevEco Studio 打开 `harmony/`，配置设备签名并安装。首次输入上一步的家庭 HTTPS 网址，之后从知伴图标进入。手机上的 `127.0.0.1` 指手机本身。构建、权限及设备验收说明见 [鸿蒙客户端说明](harmony/README.md)。

## 健康记录怎样工作

| 用户说了什么 | 知伴怎样处理 |
|---|---|
| “我今早量的血压是 138/82。” | 识别为本人的读数；按用户选择确认保存，或在开启自动记录后保存。 |
| “正常血压是多少？”“假设血压是 138/82 呢？” | 当作知识问题回答。 |
| “我爸刚量了血压，138/82。” | 就这次提问回答，不写进提问者本人的健康记录。 |
| 只发血压计或检查单的照片 | 解读能看清的内容。记入本人的记录时，由使用者确认归属与数值。 |

健康记录留在当前设备的当前浏览器或客户端里。聊天内容在当前页面会话中使用。调用问答、识图、语音识别或云端朗读时，所需内容会经家庭服务发送给 AIHubMix，再由相应模型服务处理。升级后首次使用会提示确认。网页与鸿蒙端分别保存本机记录；清除浏览器数据、清除应用数据或卸载可能一并删除记录。共用一台设备的人可以看到其中的健康本。

到期后再打开知伴，可以填写近况、改日再问或停止回访。提醒内容和通知能否在关闭应用后出现，取决于日历或鸿蒙通知授权。这里提供的是根据用户自己填写的信息进行回访，不连接血压计或手表进行实时测量。

## 开发与验证

- `web/` 包含适老界面、图片处理、录音、朗读、健康记录与回访逻辑。
- `server/` 对接 AIHubMix 的问答、语音识别和朗读接口，并管理家庭访问。`server.mjs` 提供静态网页及这些接口。
- `harmony/` 是用于 HarmonyOS 的 DevEco Studio 工程。
- 运行 `node --test tests/*.test.mjs` 检查健康归属、语音录入等逻辑。接口测试使用模拟的云端响应，实际调用计入所用 AIHubMix 账户。

随包配置面向家庭试用。准备对公众运营时，服务提供者还需办理适用的网站或应用备案、生成式 AI 服务登记及相关公示。[网信办生成式 AI 服务公告](https://www.cac.gov.cn/2026-09/14/c_1791136833136332.htm)
